# /qed-boost: Instant Q.E.D. High-Assurance Context Boost & Actuality Audit

Boost the agent's context with the full Q.E.D. High-Assurance Engineering Standard, run pre-flight anti-duplication radar, analyze blast radius, and audit codebase actuality and health.

## Instructions:
1. **Activate Q.E.D. Constitution (Mode A: Quality > Speed)**:
   - Enforce prime directive: **Evidence Before Assertions**.
   - Ban vibe-coding: no unverified assertions, no loose `any` casts, no empty `catch` blocks.
   - Enforce the 4 Mandatory States: Empty, Loading, Error (with retry), and Degraded.
   - Enforce the 3 AM Test: Guard clauses, early returns, flat readable code.
2. **Anti-Duplication Radar**:
   - Run targeted codebase search (`rg`, `find`) for existing helpers, hooks, utilities, and types before writing new code.
3. **Blast Radius Analysis**:
   - Map direct callers and indirect contract/API/DB dependencies of the upcoming task.
4. **Actuality & Freshness Health Audit**:
   - Check workspace health: detect deprecated dependencies, stale configs, dead code, and leaked secrets.
   - Confirm `.env.example` is in sync and credentials are isolated.
5. **Verification Gate Readiness**:
   - Verify that test runners (`npm test`, `pytest`, `cargo test`, etc.), typecheckers, and linters are operational and ready to provide verifiable evidence.
