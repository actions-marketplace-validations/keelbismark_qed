# Q.E.D. Context Boost & Actuality Audit Skill

Use this skill when initiating complex tasks, auditing repository freshness, or boosting agent discipline.

## Instructions

1. **Constitutional Enforcement**:
   - Activate Mode A: **Quality > Speed**.
   - Directives: Evidence Before Assertions, Red-Green-Refactor TDD, the 3 AM Test.
2. **Search Before You Create (Anti-Duplication Radar)**:
   - Grep codebase for matching functions, types, and schemas before writing any new code.
3. **Blast Radius Analysis**:
   - Classify blast radius (Low/Medium/Critical). Determine direct callers and contract boundaries.
4. **Adversarial QA & Mandatory 4 States**:
   - Verify every flow handles Empty, Loading, Error (with retry), and Degraded states.
5. **Actuality and Currency Audit**:
   - Inspect package manifests and configs for deprecated APIs or unmaintained dependencies.
   - Confirm zero credential leakage.
6. **Verification Gate Preparation**:
   - Ensure the project test suite, typecheck, and linter commands are discovered and functional.
