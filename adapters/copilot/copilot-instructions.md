# Q.E.D. Engineering Standard for GitHub Copilot
# Place this file at .github/copilot-instructions.md

## General Guidelines:
- Adhere to the Q.E.D. (Quod Erat Demonstrandum) Engineering Framework.
- Never write unverified code. Favor verifiable unit tests and type safety.
- Search for existing functions and types in the codebase before introducing new ones.
- When generating UI or API handlers, always cover Empty, Loading, Error, and Timeout states.
- Follow the 3 AM Test: prioritize readability, flat guard clauses, and meaningful variable names.
