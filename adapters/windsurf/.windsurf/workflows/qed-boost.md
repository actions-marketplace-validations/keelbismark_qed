# Q.E.D. Boost & Health Check Workflow

1. **Activate Q.E.D. Constitution**:
   - Establish mode: Quality > Speed.
   - Prime Directive: **Evidence Before Assertions**.
   - Zero tolerance for vibe-coding, unverified assertions, or unhandled 4 mandatory states.

2. **Run Anti-Duplication Radar**:
   - Search the project with `grep_search` or `find_by_name` for matching utilities or types before creating new ones.

3. **Compute Blast Radius**:
   - Identify direct callers and contract boundaries affected by planned changes.

4. **Audit Actuality & Security**:
   - Verify environment variables and credentials are not leaked.
   - Audit dependencies and configuration files for freshness.

5. **Ready Verification Gate**:
   - Identify the project's test command, typecheck command, and linter command.
