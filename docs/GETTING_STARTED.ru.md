# Быстрый старт с Q.E.D.
> Quod Erat Demonstrandum: Доказательства важнее слов.

Этот гайд написан для людей: без нудной теории, без лишних шагов. Только как поставить в 1 клик, запустить в своём проекте и работать в паре с ИИ-агентом.

---

## ⚡ 1. Установка в 1 клик (Один раз на всю машину)

Выбери одну команду под свою систему. Ничего клонировать или компилировать **не нужно**.

### Для Windows (PowerShell):
```powershell
irm https://raw.githubusercontent.com/keelbismark/qed/main/install.ps1 | iex
```
*(Или для установки сразу в глобальный профиль пользователя: `& ([scriptblock]::Create((irm https://raw.githubusercontent.com/keelbismark/qed/main/install.ps1))) -Target global`)*

### Для macOS / Linux / WSL (Bash):
```bash
curl -fsSL https://raw.githubusercontent.com/keelbismark/qed/main/install.sh | bash -s -- --target global
```

### Или через npm (если установлен Node.js):
```bash
npm install -g qed-standard
```

## 🚀 2. Подключение в твоём проекте (1 команда)

Перейди в папку любого своего проекта (нового или уже существующего):

```bash
cd C:\Portfolio\OpenAntigravity   # или путь к любому твоему репозиторию
qed init
```
*(Если не ставил глобально — просто: `npx qed-standard init`)*

### Что Q.E.D. сделает за 50 миллисекунд:
1. **Определит стек**: язык (Rust, Go, TS, Python), фреймворки и тестовый раннер.
2. **Проверит кодовую базу на скрытые проблемы**: найдёт огромные файлы-монолиты и отсутствие тестов.
3. **Построит Атлас утилит**: выпишет все имеющиеся хелперы, чтобы агент не писал велосипеды.
4. **Создаст паспорт проекта (`.qed/BRIEF.md`)**: шпаргалка для агента, которую он читает перед тем, как трогать код.
5. **Установит адаптеры для твоего редактора**: положит правила в Antigravity, Cursor, Claude Code, Codex и др.
6. **Поставит Git-защиту**: включит `pre-commit` (`qed check`) и `pre-push` (`qed test`) хуки.

> 💡 **Хочешь сразу увидеть красивый паспорт проекта в терминале?**  
> Запусти:
> ```bash
> qed init --explore
> ```

## 💬 3. Как работать с агентом в повседневной жизни

Благодаря паспорту `.qed/BRIEF.md` и встроенным хукам тебе **больше не нужно писать длинные промпты**.

В любом запросе просто добавь волшебное слово: **«по qed»** или **«qed»**:

### Пример 1: Найти и починить баг
```text
👤 Ты:   «При попытке оплатить заказ вылетает 500 ошибка, найди причину и исправь по qed»

🤖 Агент:
  1. Читает .qed/BRIEF.md и активирует скилл systematic-debugging.
  2. Снимает физические логи и стек-трейс ошибки (без догадок).
  3. Пишет падающий тест payment_insufficient_funds_test (Red).
  4. Устраняет первопричину в сервисе биллинга (Green).
  5. Запускает `qed check` в терминале и показывает вывод консоли как доказательство.
```

### Пример 2: Разработка новой функциональности
```text
👤 Ты:   «Добавь экспорт отчёта в CSV по qed»

🤖 Агент:
  1. Смотрит в Атлас утилит: видит, есть ли уже генератор CSV, чтобы не дублировать код.
  2. Реализует 4 обязательных состояния: пусто, загрузка, ошибка с кнопкой «Повторить», оффлайн.
  3. Пишет читаемый код по «Тесту 3 часов ночи» (ранние возвраты, плоские условия).
  4. Прогоняет автотесты и рапортует результат.
```

## 🛡️ 4. Проверка перед коммитом (`qed check`)

Когда агент закончил работу, проверь проект одной командой:

```bash
qed check
```

Если всё чисто — увидишь зелёный щит:
```text
==========================================================
 Q.E.D. High-Assurance Mechanical Verification Engine
 Evidence Before Assertions
==========================================================
Target: C:\Portfolio\OpenAntigravity

✓ Q.E.D. Verification Gate: 100% CLEAN. Zero violations found.
  All 16 pillars and mechanical invariants satisfied.
```

## 📋 Шпаргалка команд

| Что ты хочешь сделать | Команда |
| :--- | :--- |
| **Подключить проект к Q.E.D.** | `qed init` |
| **Посмотреть паспорт и долги проекта** | `qed init --explore` |
| **Проверить проект на чистоту и антипаттерны** | `qed check` |
| **Строгая проверка (warnings = errors)** | `qed check --strict` |
| **Проверить здоровье Git, хуков и адаптеров** | `qed doctor` |
| **Обновить правила под свежий стандарт** | `qed update` |
| **Переустановить Git-хуки** | `qed hook` |
